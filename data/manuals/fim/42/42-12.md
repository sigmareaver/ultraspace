# 42-12 — Data Bus Wiring and Medium Faults

**Entry condition:** DATA BUS A DEGRADED annunciated, the bus controller
on line (the table is readable), and either:

- **one terminal dark with its feed known good** (FIM 42-11 §2 sent you), or
- **every terminal dark after FIM 42-11's cycling restored nothing** — the
  babbling-terminal theory is dead; the medium is the suspect.

Have WDM 42 open. You will be pointing at places in it.

## 1. The doctrine, once

The harness is physical (42-00-00 §2). A break partitions the bus and the
dark terminals are *contiguous from the far end*. A trunk short kills
everything. A stub fault touches only its terminal — transformer coupling
guarantees it. The DMM is the arbiter, and it only speaks to a dead bus.

NOTE: **De-energize DB-A before any ohms check** — open CB E2, CB E3,
CB A2 — and allow one second for the rails to bleed. An open breaker is
not a dead rail, and the meter refuses a live bus.

Read the trunk and you read the map: 78 ohm is a terminator seen through
unbroken cable, OL is a break in that direction, ~0 ohm is a short. A
stub tap reads its coupling winding (~2 ohm) when the run is whole.

## 2. One terminal dark, feed good

The candidate set is the stub, the board, or the trunk feeding it. Work
the terminal's own coupler (RT 12: J2; RT 5: J1):

```
 1. De-energize DB-A (NOTE above).
 2. DMM the stub tap:
       OL ................ stub open → repair the stub run
       ~0 ohm ............ stub short → repair the stub run
       ~2 ohm ............ stub is innocent → step 3
 3. DMM the trunk toward the BC (RT 12's case: seg.j1-j2 at J2):
       OL ................ break between the couplers → repair the segment
       78 ohm ............ trunk is innocent → the board is dead →
                          replace the module (IPC 42-110-001)
```

## 3. Every terminal dark (the trunk tree)

FIM 42-11 already cleared the babbling terminal. What remains is the
medium: a short anywhere on the trunk, or a break upstream of everything.

```
 1. De-energize DB-A (NOTE above).
 2. DMM at J1, toward the BC:
       OL ................ break in seg.bc-j1 → repair it
       ~0 ohm ............ short in seg.bc-j1 → repair it
 3. DMM at J1, toward J2:
       ~0 ohm ............ short in seg.j1-j2 → repair it
 4. Trunk reads clean at J1 (78 ohm both ways):
       the cable is innocent — suspect a coupler or the controller
       (FIM 42-13, pending)
```

A partition point is found from either side: OL looking at the break no
matter which coupler you stand at. That is how you confirm you are
repairing the right run.

## 4. After the repair

Re-energize in checkout order (SOM 42-30-01: terminal feeds first, then
the controller) and verify health 1.0. The error counters will still show
the episode — that is the evidence trail, leave it. If the bus does not
come back, a second fault is present: restart from the table (FIM 42-11)
with the first fault logged.

Execute the whole tree per checklist `fim-42-12`. The checklist is the
contract: it was run against every fault it names before it reached your
hands.
