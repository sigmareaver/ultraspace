# 42-30-01 — Data Bus Checkout

**From:** buses powered (SOM 24-30-01 or 24-30-03).
**To:** DB-A HEALTHY, RT 12 answering, error counters zero.

NOTE 1: Close the terminal feed **before** the controller feed. If the
controller comes on line first it will declare RT 12 FAILED, and
DATA BUS A DEGRADED will raise and then clear as the terminal answers
(42-00-00 §6). The error counter will show the lapse for the rest of the
flight. Do it in order and there is nothing to explain.

## Procedure

Execute per checklist `som-42-30-01`:

```
 1. CB A2 (RT 12 feed) ..................... CLOSE
 2. CB E2 (bus controller feed) ............ CLOSE
       DB-A health ......................... 1.0 within 2 s
 3. DB-A bus table ......................... READ
       RT 12 ............................... OK, errors 0
```

Step 2's indication is the controller's published health: 1.0 means every
scheduled terminal answered. If the health does not reach 1.0, stop here —
the table in step 3 names the suspect, and further isolation is FIM
territory, not checkout (FIM 42-11: *pending*).

If the bus table reads NO DATA, the controller itself has no feed: verify
CB E2 and BUS E before anything else (42-00-00 §5). Do not troubleshoot a
bus you cannot see.
