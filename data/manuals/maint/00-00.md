# 00-00 — Using this book

This is the **Maintenance Manual**. It answers one question: *how do I take this
part off and put the new one on without breaking something else?* It does not
answer *what is broken* — that is the FIM — and it will not tell you whether the
part you pulled was the guilty one. Nothing on this ship will.

Tasks are numbered by **part number**, not by symptom. You arrive here holding a
verdict from somewhere else, and you leave holding a functional test result.

## 1. Every task begins with the records and ends with a test

**Read the records first** (`<address> records`). The nameplate tells you the
part number you are about to order and the serial you are about to remove. A
task run against the wrong part number is a part destroyed and a position still
broken.

**Read the stores next** (`maint read`). Stores are finite. Confirm the spare is
on the shelf *before* you open the first breaker, because the state between
removal and installation is a ship with a hole in it.

**End with the system's own functional test.** Every task in this book closes by
running the SOM check for the system it touched, and the steps are reprinted
here rather than referenced, because a checklist you have to leave in order to
finish is a checklist nobody finishes. A swap is not complete when the new unit
is in the rack. It is complete when an instrument says the function is back.

## 2. De-energize means de-energize

Removal and installation refuse on a live system, the same way the meter does.
An open breaker is not a dead rail — allow the bleed time the task calls for.
The refusal names the system you have to kill.

This is not a formality the sim enforces for flavour. The interlock is the
reason you can work a bus at all while the ship is flying: everything that
touches the medium is off, so nothing you do in there can propagate.

## 3. An open position is yours to remember

A removed unit draws no current, answers nothing, and cannot jam anything. That
means pulling a babbling terminal really does cure its bus — on the spot, with
the function gone.

**Nothing will remind you.** The system display sees a unit that stopped
answering; it cannot see an empty rack, and it says the same thing either way.
The only record that the position is open is this book's stores sheet
(`maint read`) and the position itself (`<address> read`, which reads
`NOT FITTED`). Check both before you conclude that a system is broken. More than
one crew has isolated a fault that was their own screwdriver.

## 4. What the records do not say

A unit's record carries its serial, its part number, where it is fitted, its
powered hours, and every time it was fitted, removed, or installed.

It does not carry a verdict. A board that came off on suspicion reads
`not bench-tested`, because nobody has tested it — there is no bench on this
ship. The unit keeps whatever was wrong with it and nothing here will tell you
what that was. Label your removals: they are stock for a shop you have not
reached yet, and an installation always draws a fresh unit from stores.
